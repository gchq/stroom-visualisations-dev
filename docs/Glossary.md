# Glossary

Term | Description
---- | -----------
D3   | D3.js javascript visualisation library
JSON | Javascript Object Notation
UI   | User Interface
META | A document's definition file in a content pack (JSON)
NODE | A document's place in Stroom's tree of folders, in a content pack
Asset | A file of a document (e.g. a visualisation's index.html, JavaScript and CSS), which Stroom serves at /assets/<uuid>/
BEM  | Block, Element, Modifier: how the CSS classes are named, e.g. vis-legend__item--hidden
esbuild | The bundler that builds each visualisation's JavaScript and CSS
